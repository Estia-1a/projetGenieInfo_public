# Contribute

If you want to contribute you can open issues, or fork the project, implement fixes and open a pull request (PR).

Issues are used by : 
- The teaching team to manage the project (create new features, prepare the class etc).
- The Students to report bugs or possible enhancement to the class. 

PR will only be considered if they address an issues marked as need help.
